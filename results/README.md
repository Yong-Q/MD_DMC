# 168 个体系的已有本地后处理结果（2026-11-15）

本目录只整理以前已经计算的结果，没有重新运行 MD 或重新计算轨迹。

- `existing_diffusion_20261115.csv`：168 个体系逐条列出 MOF、DMC/LiFSI 比例、重复编号、调度状态和已有自扩散结果。42 个体系的 15 ns 分析已完成；1 个轨迹完成但后处理内存不足；125 个此前取消。未完成分析的数值留空，空值不是零。
- `existing_conductivity_windows_20261115.csv`：上述 42 个体系各自已有的 5 个 Einstein–Helfand 集体电导率窗口，共 210 行。每一行对应一个拟合滞后时间窗口，窗口重叠、并非独立重复。原始结果按 1–4、2–5、3–6、4–7、5–8 ns 的滞后时间拟合，这些是此前已有结果，并非最新 v3 自动筛选结果。

`dmc_per_lifsi_molar_ratio` 是 DMC 分子数与 LiFSI 对数之比，各体系有 50 对 LiFSI；`*_concentration_pore_M_proxy` 是以构建时估计的可连通孔体积计算的名义浓度（mol/L），不是实验投料浓度或轨迹测得的局部浓度。

扩散表中 `li_linear_D_cm2_s` 是先前线性 MSD 拟合结果；`li_loglog_slope_median` 为先前选区的双对数斜率中位数。`li_kinisi_*` 仅在原有结果明确标记 `kinisi` 时填写；它采用原后处理设置，本表不重新核验其漂移修正、协方差条件数和收敛性。`fsi_anchor_D_cm2_s` 是 FSI 氮原子锚点扩散，不是分子质心。`li_diffusion_criteria_met`、拟合窗口和来源沿用旧记录；结果没有因此自动获得物理验证。

集体电导率单位 mS/cm，按整个模拟盒体积和模型部分电荷归一化。`conductivity_signed_mS_cm` 保留带符号的拟合斜率换算值，负值是有限采样或拟合不稳定的诊断，不表示物理负电导率；相应 `conductivity_mS_cm` 留空。`fit_r2` 是旧拟合指标，不能独立证明收敛。不同窗口应结合原曲线和独立重复检查，不能当作重复样本求标准差。

这批模型使用固定 MOF 骨架、缩放电荷和有限长度轨迹；孔体积、温度、结构平衡、有限尺寸与实验样品条件可能影响比较。此表没有上传轨迹或图像。不同浓度的 4 次独立重复可按需求另行汇总；不要把未完成、失败或空值记为零。
